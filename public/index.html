User ID

Maksimal 50 User ID/WebSocket. SAVE menyimpan akun + room + delay ROLL + teks FLOOD.

Room

CommandBox

ROLL menggunakan maksimal 50 WebSocket yang sudah login: ENTER → LEAVE, lalu jeda antar-WebSocket. Tidak ada LOGIN/LOGOUT di dalam ROLL.

FLOOD

Semua WS mengirim Flood 1 secara bergiliran, lalu Flood 2 hingga Flood 8. Delay Socket mengatur jeda antar-WS; Delay Flood mengatur jeda setelah semua WS mengirim teks yang sama. Putaran terus berulang sampai STOP FLOOD. STOP menghentikan pengiriman baru. SAVE FLOOD/LOAD FLOOD menyimpan atau memuat pesan dan jeda.
